# Internationalisation

Footera supports Malagasy (`mg`), English (`en`) and French (`fr`). The selected language is persisted in `localStorage` under `footera.language`.

Use `useTranslation()` in React components and add every user-facing message to all three catalogs in `src/i18n/index.tsx`. Components should reference stable keys (for example `t('auth.login')`) instead of embedding translated copy in JSX. Keep domain values received from the API separate from UI messages; translate those through an explicit label map when they are user-facing.

The catalogs currently cover language selection, shared loading states, the header/logout flow, and authentication. Existing feature screens still contain French UI strings and must be migrated feature by feature before the frontend can be considered fully internationalised.
